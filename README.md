# Ishara (working name)

A sealed screen tutor. Hold a key, ask a question out loud, and a pointer moves to the right spot on the
page. Every decision comes from a sealed model on 0G with a request id you can check. If 0G cannot be
reached, the tutor says it cannot decide. It never guesses.

Built for ETHGlobal Mumbai, 5-7 Nov 2026. Tracks: 0G Physical AI, Build with 0G PC, EF Best CROPS App.
